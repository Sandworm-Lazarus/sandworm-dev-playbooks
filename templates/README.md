# Report templates

[Home](../README.md) · [Original playbooks](../playbooks/review-agent-extension.md)

Copy a template into your own working directory and replace bracketed fields with evidence. These are original Sandworm Arsenal templates under the repository MIT license. Unobserved results stay marked **Not run** or **Unknown**.

| Template | Use for |
| --- | --- |
| [Security finding](security-finding.md) | A reproducible code or configuration defect |
| [Threat model](threat-model.md) | System boundaries, assets, abuse paths, and controls |
| [Model evaluation](model-evaluation.md) | Comparable quality, latency, and cost results |
| [Agent extension review](extension-review.md) | Permissions, hooks, dependencies, and outbound data |
| [Detection rule](detection-rule.md) | Detection intent, data requirements, fixtures, and tuning |
